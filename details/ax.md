## Overview

Local-first telemetry and recall graph for AI coding agents.

## Features

- Ingests Claude Code, Codex, Cursor, OpenCode, and Pi sessions
- Stores sessions, turns, tool calls, skills, costs, dispatches, and OTLP telemetry
- CLI, local dashboard, and read-only MCP server
- SurrealDB-backed local graph
- Works across multiple agent harnesses
