## Overview

Framework-agnostic, local-first memory lifecycle for AI coding agents.

## Features

- Rust CLI and TUI.
- SQLite/FTS recall.
- Audit, redaction, and forgetting flows.
- Source-linked evidence.
- Portable skill guidance.

## Use Cases

- Long-running coding-agent sessions.
- Local/private agent memory.
- Reviewable memory lifecycle workflows.

Free/open-source.
